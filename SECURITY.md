# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security reports.

Email [friends@dreamdata.io](mailto:friends@dreamdata.io) with the details and we will route
it to the security team. Dreamdata's security posture, certifications, and subprocessors are
published at <https://trust.dreamdata.io>.

## Scope

This repository holds the public connector manifest and documentation for the hosted
Dreamdata MCP server at `https://mcp.dreamdata.io/mcp`. Reports about the hosted service,
its OAuth flow, or the Dreamdata Platform are all in scope for the address above.
